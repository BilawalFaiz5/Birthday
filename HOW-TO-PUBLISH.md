# How to publish Uzma's birthday website (free, no coding)

You need: a free GitHub account (github.com) and about 10 minutes.
Everything can be done from a phone browser or a computer.

## Before you publish (2 minutes)

1. **Letter** – open `letter.js`, paste your Roman Urdu letter between the two backticks (`` ` ``), replacing the warning text.
2. **Photos** – put your pictures in the `photos` folder named `photo1.jpg` … `photo6.jpg` (JPG, ideally under 500 KB each).
3. **Music (optional)** – put an MP3 in the `music` folder named `song.mp3`. Use music you have the right to use. If there is no file, the site still works and the player just shows a hint.

## Publish with GitHub Pages

1. Go to https://github.com and sign up / log in.
2. Tap **+** (top right) → **New repository**.
3. Name it something private-looking, e.g. `uzma-surprise-2026`. Set it to **Public** (GitHub Pages on free accounts needs Public). Tap **Create repository**.
4. Tap **uploading an existing file** (the link on the empty repo page).
5. Unzip `uzma-birthday.zip` and drag in **everything inside** the folder (`index.html`, `style.css`, `script.js`, `letter.js`, and the `photos` and `music` folders). `index.html` must be at the top level, not inside another folder.
6. Tap **Commit changes**.
7. Go to **Settings → Pages**.
8. Under **Build and deployment**, set Source to **Deploy from a branch**, Branch to **main**, folder **/ (root)**, then **Save**.
9. Wait 1–3 minutes and refresh. A box appears: *"Your site is live at https://YOUR-USERNAME.github.io/uzma-surprise-2026/"*.
10. **Open that link on your own phone first.** Check the letter, photos, buttons and music.
11. Send the link to Uzma on WhatsApp. 💌

## Easier alternative: Netlify Drop (no account needed to try)

1. Go to https://app.netlify.com/drop
2. Drag the unzipped `uzma-birthday` folder onto the page.
3. You get an `https://….netlify.app` link instantly. Sign up (free) to keep it permanently.

## Updating later

On GitHub, open the file → pencil icon → edit → **Commit changes**. The site refreshes in about a minute.

## Good to know

- The link is public: anyone who has it can open it. Share it only with Uzma, and use an unguessable repository name.
- Photos in a public repo are public too. Don't upload any you wouldn't want seen by others.
- If a change doesn't show, refresh the page or open it in a private tab (phones cache).
